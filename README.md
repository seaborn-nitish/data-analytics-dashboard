# Data Analytics Dashboard

## 📌 Project Description
A web-based dashboard that allows users to upload CSV files and visualize data using graphs and summary statistics.

## 🚀 Features
- Upload CSV file
- Data cleaning (missing values, duplicates)
- Data preview
- Summary statistics
- Graphs:
  - Histogram
  - Bar chart
  - Heatmap

## 🛠️ Technologies Used
- Python (Flask)
- Pandas
- Matplotlib
- Seaborn
- HTML, CSS

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/
